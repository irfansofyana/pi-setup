# Goal Loop V2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Improve the Pi `/goal` extension so auto-continue is reliable and the agent can inspect/update goals through native tools with evidence tracking.

**Architecture:** Keep the repo-stored Pi extension as a single portable template in `pi/extensions/goal-loop/index.ts`. Pure helpers stay exported and tested with Node's built-in runner; Pi runtime behavior registers slash commands, lifecycle hooks, and model-callable tools.

**Tech Stack:** TypeScript, Pi extension API, local JSON-schema helpers for tool parameters, Node.js built-in test runner, JSON state under `~/.pi/agent/goal-loop/state.json`.
